## 🚀 Key Technological Breakthroughs

### 1. ♾️ Perpetual Zero-Cost Architecture (No Expiry, No Subscriptions)
- **100% Client-Side In-Browser Engine**: Runs all Black-Scholes Greeks, 5-Gatekeeper scorecards, BlackRock Aladdin VaR/drawdowns, DCF valuations, and Next-Day T+1 predictive modeling inside your browser using TypeScript, React 19, and Tailwind CSS 4.
- **Permanent Cloud CDN Hosting**: Automatically compiled and published via GitHub Actions to GitHub Pages. Zero monthly hosting fees, zero server maintenance, and never expires.
- **Optional Free Gemini AI**: Enter your personal free Google AI Studio API Key in settings, or seamlessly rely on the deterministic CFA quant synthesis engine with zero API calls.

### 2. ⚡ Continuous Perpetual Synchronization
- Built-in multi-source market sync engine:
  - **Server-Sent Events (SSE)** when connected to the local Express backend.
  - **Direct Quant Micro-Tick Feed**: Runs client-side high-precision sub-second simulated ticks, bid-ask spreads, and macroeconomic volatility updates 24/7 forever, even when completely offline.

### 3. 🖥️ Dedicated Windows Desktop App
- Launch instantly without browser address bars, navigation buttons, or tabs:
  - Run **[`run_alphavault_desktop.bat`](./run_alphavault_desktop.bat)** to open a native, hardware-accelerated frameless desktop window.
  - Can be pinned to your Windows Taskbar and Start Menu.

### 4. 📱 Android Native Mobile App & PWA
- **PWA (Zero-Install)**: Open the web link in Chrome or Edge on Android and tap **"Add to Home Screen"** or **"Install App"**. Launches full-screen with offline support via Service Worker (`sw.js`).
- **Android Studio Project**: Complete Jetpack Compose WebView shell under [`app/`](./app/) with hardware acceleration, edge-to-edge rendering, and back-button history navigation.

## 🛠️ Quickstart

### Running Locally

```bash
# 1. Clone repository
git clone https://github.com/eofficesubhendubarua-hue/AlphaVault-terminal-Sharemarket-indepth-Analysis.git
cd AlphaVault-terminal-Sharemarket-indepth-Analysis

# 2. Install dependencies
npm install

# 3. Run full verification suite (19/19 tests)
npm test

# 4. Start local development server
npm run dev
# Open http://localhost:3000 in your browser
```

### Windows One-Click Launchers
- **`run_alphavault.bat`**: Syncs Aladdin Python quant engine and launches the local web server.
- **`run_alphavault_desktop.bat`**: Opens the frameless Windows desktop application window.
